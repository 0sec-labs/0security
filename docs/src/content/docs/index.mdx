## Install

<Tabs syncKey="install">
  <TabItem label="macOS / Linux">
    ```bash
    curl -fsSL https://raw.githubusercontent.com/0sec-labs/0security/main/install.sh | bash
    ```

    The script supports Apple Silicon macOS and x64 or ARM64 Linux. It checks the binary's checksum, installs it to `~/.0/bin` and adds that folder to your `PATH`. The command is `0security`, and `0` is a short alias for it. Set `INSTALL_DIR` to install somewhere else.

    Windows is experimental. Download `0security-windows-x64.exe` from [Releases](https://github.com/0sec-labs/0security/releases/latest). The same file is also published as `0-windows-x64.exe`, which is kept so existing installs can update. Rename the file to the command name you want.
  </TabItem>
  <TabItem label="Docker">
    ```bash
    docker run --rm -e OPENAI_API_KEY \
      -v "$PWD:/work/source:ro" ghcr.io/0sec-labs/0security:latest --help
    ```

    The image runs CLI commands, not the browser app. Mount your code and pass your model key. See [Server mode and Docker](/server-mode/).
  </TabItem>
  <TabItem label="Source">
    ```bash
    git clone https://github.com/0sec-labs/0security.git && cd 0security
    pnpm install --frozen-lockfile && pnpm build
    node packages/cli/dist/index.js web
    ```

    You need Node.js 24 or newer and pnpm. A source build has no global `0security` command, so start it with `node packages/cli/dist/index.js`.
  </TabItem>
</Tabs>

## Update

0 checks GitHub for a new release when it starts in a terminal, at most once a day, and installs it. A console that stays open checks every six hours and shows an update card with **Update and restart**. To change this, open **Settings → Updates** and choose `off`, `notify` or `automatic`. See [Update checks](/configuration/#update-checks).

To update now, run:

```bash
0security config doctor upgrade
```

The command verifies the checksum, then replaces the binary you started it from.

Copies older than 0.33 cannot update from the console. Run the installer again once. It installs the latest release and keeps your settings.

```bash
curl -fsSL https://raw.githubusercontent.com/0sec-labs/0security/main/install.sh | bash
```

## Start your first thread

<Steps>

1. Run `0security`. The browser app opens at `http://127.0.0.1:48123`. You do not need an account.

2. Open **Settings → Models** and add a provider key or sign in. See [Models](/models/).

3. Press **New thread**, pick a folder and describe the job. For example: "Review this folder for injection bugs and verify what you find". See [Threads](/threads/).

4. Open **Findings**. Each finding links to its evidence. See [Findings](/findings/) for how a finding becomes verified.

</Steps>

The **Finish setting up** card in the sidebar tracks the model and thread steps.

:::caution
Only point 0 at systems you own or are authorized to test.
:::

## Scan from the terminal

Everything the console does is also a command. Connect a model first, then scan a folder and read the findings.

```bash
export OPENAI_API_KEY=...
0security scan ./your-repo
0security findings list
```

To export findings, add `--format sarif` or `--format json` to `0security findings list`. To scan only what a branch changed, see [Pull request checks](/ci/). The [CLI reference](/commands/) lists every command.

## The words 0 uses

| Term | Meaning |
| --- | --- |
| Thread | A conversation with the agent. You describe a job, and it plans, runs tools and records findings. See [Threads](/threads/). |
| Sentinel | A named, standing job. It runs on a schedule, on a pull request or by hand. See [Sentinels](/sentinels/). |
| Computer | The machine where threads run: this one, a VM or a remote server. See [Computers](/computers/). |
| Folder | The directory a thread works in. |
| Skill | A folder of instructions the agent loads when a task needs it. It is not code. See [Skills](/skills/). |
| Extension | An installable git folder, pinned to a commit. It can bundle skills, scripts, MCP servers and a connection. See [Extensions](/extensions/). |
| Finding | A security issue with evidence. A finding without reproduced evidence is a lead. See [Findings](/findings/). |

## Troubleshooting

To check the runtime, your model provider and the CLIs on your path, run:

```bash
0security config doctor
```

### 0: command not found

Open a new terminal. Or add 0 to your path:

```bash
export PATH="$HOME/.0/bin:$PATH"
```

A source build has no global `0security`. Run `node packages/cli/dist/index.js` instead.

### Download or checksum error

The installer refuses a binary that does not match the release `checksums.txt`. Run it again. Release assets are `0security-darwin-arm64`, `0security-linux-x64` and `0security-linux-arm64`. The installer falls back to the older `0-<platform>` names, which are published too so existing installs can update. For Windows, download `0security-windows-x64.exe` yourself. Intel Macs have no native release, so use Docker or a source build. `0security config doctor upgrade` does not support Windows.

### Model provider shows missing or bad

0 found no usable model credential. Connect one in **Settings → Models** or export a key. A provider marked configured has a key, but 0 does not test it until the first request. See [Models](/models/).

### database is locked

Two processes are writing the same SQLite file. Stop the other one. Do not delete a live database.

`0security config doctor --fix` moves a damaged file aside and creates a new one. It does not recover rows, so back up first.

### The app does not open

Start 0 without opening a browser, then open the URL it prints:

```bash
0security --no-open
```

On macOS, the first access to Desktop, Documents or Downloads asks for permission. If you declined, enable the app that runs 0 under **System Settings → Privacy & Security → Files & Folders**.

### Docker prints help and exits

The image runs `0security --help` by default and mounts nothing. Pass your folder, your key and a command. See [Server mode and Docker](/server-mode/).

### Still stuck

Run `0security config doctor` and [open an issue](https://github.com/0sec-labs/0security/issues) with its output, the command and the error. Remove keys, tokens and target data first. To report a vulnerability in 0 itself, follow [SECURITY.md](https://github.com/0sec-labs/0security/blob/main/.github/SECURITY.md).
